# 实验 2：图像消融实验 —— CNN 删核（沉睡核假说修正）

> 实验日期：2026-08-23　|　周次：第 14 周（深度学习收官）　|　方向：B 图像

## 一、实验目的

消融实验：把第 12 周判定为"沉睡核"的 conv1 核 5 从 CNN 中删除，观察测试精度变化。
顺带检验一个更重要的问题：**第 12 周的"沉睡核"判定（平均激活 ≈ 0.000）到底对不对？**

## 二、数据集与模型

**数据集**：Fashion-MNIST（60,000 训练 / 10,000 测试，28×28 灰度，10 类服装）

**模型**：CNN（第 12 周训练，测试精度 89.65%）

```
conv1: 1→8 通道, 3×3, padding=1  (+ bias=True) → BN → ReLU → MaxPool(2)
conv2: 8→16 通道, 3×3, padding=1  (+ bias=True) → BN → ReLU → MaxPool(2)
dropout(0.5) → fc: 784→10
```

⚠️ 关键细节：**Conv2d 默认 bias=True**——每个核 = weight(3×3 图案) + bias(1 个嗓门)。本实验第一个版本只删了 weight，漏了 bias，差点得出错误结论（见 §五）。

## 三、超参数

| 超参 | 值 |
|---|---|
| 优化器 / lr | Adam / 0.001 |
| 损失 | CrossEntropyLoss |
| epochs / batch | 10 / 64 |

## 四、实验设计（消融协议）

1. 加载已训练模型（**注意：每次运行脚本都从 pth 重新加载 = 出厂状态**，置零只改内存，不写回文件）
2. 测原始精度（基线）
3. 手术 1：仅清零 `conv1.weight[5]`
4. 手术 2：清零 `conv1.weight[5]` + `conv1.bias[5]`（完整删核）
5. 每次手术后重测精度 + 验证手术生效（打印权重、统计激活比例）

**测试函数封装**：`test(model)` 遍历 test_loader 返回准确率——同一逻辑调用多次，必须写成函数（复用是函数存在的意义）。

## 五、实验结果

| 状态 | 测试精度 | 掉点 |
|---|---|---|
| 原始模型 | 89.65% | — |
| 只删 weight（漏删 bias） | 88.96% | -0.69% |
| **完整删核**（weight + bias） | **88.52%** | **-1.13%** |
| 核 5 bias 值 | 0.2198（正数） | — |
| 删干净后激活比例 | 0.0000（真·恒 0） | — |

## 六、分析：第 12 周"沉睡核"结论被推翻

第 12 周判定核 5 为"沉睡核"的依据：ReLU 后平均激活 ≈ 0.000 + 特征图"全黑"。
本实验数据证明**判定错误**：

1. **bias = 0.2198 解密矛盾**：核 5 天生输出偏正（每像素 +0.2198），ReLU 后激活比例高达 **100%**（每个像素都是正数）。平均激活 ≈ 0 是因为**数值小**（被四舍五入成 0.000），不是**没激活**——**值小 ≠ 没激活**。

2. **视觉"全黑"是骗局**：0.0001 级别的值在热力图 colormap 上渲染为纯黑。**视觉黑 ≠ 数值 0**。

3. **删 weight 掉 0.69%**：核 5 的权重图案携带真实特征信息（约 69 张测试图的分类依赖它）。

4. **再删 bias 又掉 0.44%**：连 bias 那个常数偏置都在影响决策边界。**删核必须删干净（weight + bias）**——只删 weight 的 88.96% 是"半删"假象。

5. **死核的唯一正确标准：激活比例 = 0（恒 0 输出）**。统计平均激活不可靠——bias 会骗平均值。

## 七、结论与经验

1. **消融实验修正统计结论**：判断核的重要性，看"删掉后掉不掉点"（消融），不看"平均激活"（统计）。平均激活 0 的核 ≠ 没用的核。

2. **输出反查（打印权重/激活比例）是验证手术生效的必要手段**——本实验靠它抓到了 bias 漏删。实验代码必须有"自检输出"。

3. **模型状态活在内存里**：`weight[5] = 0` 只改当前运行的对象；重新运行脚本 / `load_state_dict` = 回到出厂状态。想保存手术结果必须 `torch.save` 新文件。

4. **Conv2d 参数结构**：weight（核图案）+ bias（核嗓门），删除/修改核时两者都要处理。
