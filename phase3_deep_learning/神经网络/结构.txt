## 一、最小单元：单个神经元

```
x₁ ──→ [w₁]
x₂ ──→ [w₂]  ──→  Σ + b  ──→  激活函数  ──→  h
x₃ ──→ [w₃]
```

$$h = f(w_1x_1 + w_2x_2 + ... + w_nx_n + b)$$

| 角色 | 含义 |
|---|---|
| **w（权重）** | 每条输入的"重要程度"，正=正向影响，负=反向影响 |
| **b（偏置）** | 神经元的"固有倾向"，没有输入时的基线 |
| **激活函数** | 把线性结果"掰弯"，引入非线性 |
| **h（输出）** | 这个神经元的"判断结果" |

> 一个神经元 = 听各方意见（wx），加上自己的倾向（b），按规则（激活函数）做一个决定。

---

## 二、一层：多个神经元并行

```
               ┌─→ 神经元₁ ─→ h₁
x₁ x₂ x₃ ──→ ─┼─→ 神经元₂ ─→ h₂
               └─→ 神经元₃ ─→ h₃
```

矩阵形式：

$$h = f(Wx + b)$$

| 符号 | 形状 | 含义 |
|---|---|---|
| x | (n,) | n 维输入 |
| W | (m, n) | m 个神经元，每个观察 n 个输入 |
| b | (m,) | 每个神经元一个偏置 |
| h | (m,) | m 个输出，代表 m 种"判断" |

---

## 三、多层网络 = 深度

```
输入 (n维)
   ↓ W₁ + 激活
隐藏层1 (m₁维)
   ↓ W₂ + 激活
隐藏层2 (m₂维)
   ↓ W₃ + 激活
输出层 (k维)
```

### 矩阵形状规则

> **前一层的输出维度 = 下一层的输入维度**

```
W₁: (m₁ × n)   输入 n 维 → 输出 m₁ 维
W₂: (m₂ × m₁)  输入 m₁ 维 → 输出 m₂ 维
W₃: (k × m₂)   输入 m₂ 维 → 输出 k 维
```

### 为什么需要"深"？

浅层网络每层只能做一个简单的视角转换。深层网络逐步抽象：

```
图片像素 → [Layer 1] 边缘/颜色 → [Layer 2] 简单形状 → [Layer 3] 器官 → [Layer 4] 对象
```

> **层数 = 抽象层级。**

---

## 四、激活函数：为什么必须非线性？

$$
\text{如果每层都只做 } Wx+b \text{：}
$$
$$
W_3(W_2(W_1x + b_1) + b_2) + b_3 = W'x + b' \quad \text{还是线性的，深了没用}
$$

| 激活函数 | 公式 | 输出范围 | 用在哪 |
|---|---|---|---|
| **ReLU** | max(0, x) | [0, ∞) | 隐藏层（默认） |
| **Sigmoid** | 1/(1+e⁻ˣ) | (0, 1) | 二分类输出层 |
| **Tanh** | (eˣ-e⁻ˣ)/(eˣ+e⁻ˣ) | (-1, 1) | RNN 中常见 |
| **Softmax** | eˣᵢ/Σeˣ | (0, 1)，和为 1 | 多分类输出层 |

---

## 五、损失函数：衡量"差多少"

| 任务 | 损失函数 | 搭配的激活 | 为什么搭配 |
|---|---|---|---|
| 回归 | **MSE** | 不用激活 | 输出实数，梯度畅通 |
| 二分类 | **BCE** | Sigmoid | BCE 自带梯度放大器，抵消 Sigmoid 的饱和 |
| 多分类 | **CrossEntropy** | Softmax | CE 比较概率分布差异 |

### Sigmoid + MSE 为什么不行？

```
Sigmoid 输出 0.01 → Sigmoid 梯度 ≈ 0
MSE 梯度 = 2(0.01 - 1) = -1.98（很大！）
总梯度 = (-1.98) × (≈0) = ≈0
```

> **MSE 想调，Sigmoid 把门关了。BCE 在梯度里放了一个放大器，把门撬开。**

## 六、反向传播：梯度怎么传？

### 三步走

```
① 正向：x → h₁ → h₂ → ... → ŷ → L
② 反向：L → ... → h₂ → h₁ → ∂W₁
③ 更新：W₁ = W₁ - η × ∂L/∂W₁
```

### 链式法则

$$\frac{\partial L}{\partial W_1} = \frac{\partial L}{\partial \hat{y}} \times \frac{\partial \hat{y}}{\partial h_2} \times \frac{\partial h_2}{\partial h_1} \times \frac{\partial h_1}{\partial W_1}$$

> 类比：多米诺骨牌倒塌后，从最后一张倒着往前追查每一张的责任。

## 七、优化器：参数怎么更新

| | SGD | SGD + Momentum | Adam |
|---|---|---|---|
| 原理 | w = w - η×梯度 | 累加历史梯度（惯性） | 每个参数自适应学习率 |
| 震荡 | 多（山谷里来回弹） | 少（震荡互相抵消） | 很少 |
| 速度 | 慢 | 中 | 快 |
| 调参 | η | η + β | 默认值就够 |
| 什么时候用 | 几乎不用了 | 偶尔 | **默认首选** |

> SGD = 走一步看一步 | Momentum = 骑自行车 | Adam = 自动挡汽车

---

## 八、参数 vs 超参数

| | 参数 | 超参数 |
|---|---|---|
| 谁来定 | **模型自己学** | **你手工设** |
| 举例 | w, b | 学习率, 层数, 神经元个数 |
| 训练中 | 每一步在变 | 全程不变 |

## 九、完整训练循环（你已经在 PyTorch 里写过了）

```python
for epoch in range(N):          # 重复 N 轮
    y_pred = model(x)           # ① 正向：算预测
    loss = criterion(y_pred, y) # ② 算损失
    optimizer.zero_grad()       # ③ 清空旧梯度
    loss.backward()             # ④ 反向：追责
    optimizer.step()            # ⑤ 更新参数
```
