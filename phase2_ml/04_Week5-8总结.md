## 一、ML 核心范式

**机器学习 = 用模型从数据中学习，通过最小化损失来优化参数。**

```
数据 → 模型(参数θ) → 预测 ŷ → 损失L(ŷ, y) → 梯度下降更新θ
```

---

## 二、基石概念 (Week 5)

### 过拟合 vs 欠拟合
- 过拟合：训练集 100%，测试集差 → 死记硬背
- 欠拟合：训练集低，测试集也低 → 没学会
- 诊断：看训练/测试误差曲线
- 药方：正则化(λw²)、早停、更多数据、Dropout

### 数据切分
```
训练集（练习册）| 验证集（模拟考）| 测试集（高考，只用一次）
⚠️ 先切分再预处理，否则数据泄露
```

### 评估指标
| 指标 | 场景 |
|------|------|
| 准确率 | 类别均衡时 |
| 精确率 | 不误伤（垃圾邮件） |
| 召回率 | 不放过（癌症筛查） |
| F1 | 平衡精确率和召回率 |
| R² | 回归：比瞎猜好多少 |

## 三、5 个分类模型 (Week 6)

| 模型 | 原理 | 一句话 |
|------|------|--------|
| 逻辑回归 | wx+b → sigmoid → 概率 | 画一条直线分两半 |
| KNN | 算距离 → 找K个 → 投票 | 找邻居问答案 |
| 决策树 | Gini 分叉 → if-else 问问题 | 一串"是/否"问题 |
| 随机森林 | 100棵树投票 | Bagging：三臭皮匠顶诸葛亮 |
| XGBoost | 每棵纠正前一棵 | Boosting：串行补漏洞 |

### 逻辑回归梯度推导
```python
z = X@w + b
ŷ = sigmoid(z)           # 压缩到 0~1
L = -[y log ŷ + (1-y) log(1-ŷ)]  # 交叉熵
∂L/∂w = (ŷ - y)·X        # 梯度（形式上和线性回归一样）
w ← w - lr·∂L/∂w
```

### KNN 核心
- K=1：过拟合（训练 100%）
- K=5：最佳平衡
- K=全部：欠拟合（永远猜多数类）
- 致命弱点：维度灾难（高维时所有点一样远）

## 四、科研工具链 (Week 7)

### cross_val_score（交叉验证）
切 K 份，轮流训练，取平均 → 比单次切分可靠

### GridSearchCV（自动调参）
```
参数网格 × 交叉验证 = 自动找最优组合
```

### StandardScaler（标准化）
```
x_scaled = (x - μ) / σ → 所有特征均值=0，方差=1
⚠️ fit 只对训练集，transform 用到测试集
```
- 逻辑回归、KNN 需要标准化
- 决策树、随机森林不需要

### Pipeline（防数据泄露）
```python
pipe = make_pipeline(StandardScaler(), LogisticRegression())
pipe.fit(X_train, y_train)  # 自动先标准化再训练
pipe.predict(X_test)        # 自动先标准化再预测
```

### SelectKBest（特征选择）
挑出和标签关系最强的 k 个特征，砍掉噪声

### 分类 vs 回归
```
分类：LogisticRegression, KNeighborsClassifier, RandomForestClassifier
回归：LinearRegression, KNeighborsRegressor, RandomForestRegressor
评估：accuracy_score → r2_score
```

## 六、代码模板（用 Python 3 跑）

```python
# 分类模板
from sklearn.ensemble import RandomForestClassifier
from sklearn.model_selection import cross_val_score

scores = cross_val_score(RandomForestClassifier(), X, y, cv=5)
print(f"准确率: {scores.mean():.3f}")

# 回归模板
from sklearn.linear_model import LinearRegression
from sklearn.model_selection import cross_val_score

scores = cross_val_score(LinearRegression(), X, y, cv=5, scoring='r2')
print(f"R²: {scores.mean():.3f}")
